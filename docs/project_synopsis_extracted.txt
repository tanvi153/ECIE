Enterprise E-Commerce Intelligence Engine (E-CIE)

1. Introduction

Multi-vendor e-commerce marketplaces generate enormous volumes of customer feedback, product metadata, and seller information every day, yet this information typically resides in disconnected silos that make real-time, end-to-end analysis difficult. As a result, brand managers and operations teams are often reactive rather than proactive: product flaws and declining customer sentiment are usually noticed only after ratings drop, while shoppers struggle to discover relevant products among millions of listings because feedback signals are rarely connected to discovery and recommendation systems.

The Enterprise E-Commerce Intelligence Engine (E-CIE) addresses this gap by unifying the analytics lifecycle for a large, multi-category e-commerce feedback dataset. Approximately 2–3 million real customer reviews and their associated product, store, and user metadata — drawn from the Amazon Reviews 2023 corpus (McAuley Lab) across the Cell Phones & Accessories, Electronics, Video Games, and Tools & Home Improvement categories — are restructured into a clean, relational PostgreSQL warehouse. Unstructured review text is mined using Natural Language Processing (NLP) to classify customer sentiment, while product metadata powers a content-based recommendation engine. The resulting insights are served through an interactive Streamlit web application and executive Power BI dashboards. The platform is intended for e-commerce brand managers, category analysts, and platform teams who need to understand how customers feel about products and help shoppers discover items they are likely to want.

2. Objective

The primary objective of this project is to design and implement an enterprise-grade data intelligence platform that transforms roughly 2–3 million raw Amazon review and product records (sampled from four product categories) into a normalized, five-table relational data warehouse, and to train two complementary machine learning models: (a) a text-based customer sentiment classifier, and (b) a content-based product recommendation engine.

The secondary objective is to expose these insights through two complementary interfaces: a live Streamlit web application that lets business users test review sentiment in real time and explore “similar product” recommendations, and a multi-page Power BI executive dashboard that tracks review-driven KPIs such as rating trends, sentiment distribution by category/store, and price-to-rating relationships. A further objective is to package the entire solution using Docker and automate testing and deployment through a GitHub Actions CI/CD pipeline, so that the system is reproducible and cloud-deployable.

3. Scope

The scope of this project covers the following areas:

Data Sourcing & Sampling: Streaming and reservoir-sampling ~2–3 million reviews (and their linked product metadata) from four Amazon Reviews 2023 categories, avoiding the need to download the full multi-gigabyte source files.

Data Warehousing: Restructuring the sampled data into 5 relational tables — reviews, review_text, products, stores, and users — in PostgreSQL, with enforced primary/foreign keys and star-schema analytical views.

Data Cleaning & Feature Engineering: Connecting Python (via SQLAlchemy) to PostgreSQL to handle nulls (e.g., missing price/main_category), parse timestamps, and vectorize review and product text using TF-IDF.

NLP-based Sentiment Analysis: Classifying customer reviews as positive, negative, or neutral directly from review text, independent of the numeric rating (to avoid label leakage).

Content-Based Product Recommendation: Recommending similar products from product titles, categories, and metadata using TF-IDF and nearest-neighbour similarity, addressing the extreme sparsity of user-product interactions in the dataset.

Experiment Tracking: Logging model metrics and parameters with MLflow, and serializing trained models with Joblib.

Business Intelligence Dashboarding: A multi-page Power BI report connected directly to PostgreSQL, covering rating trends, sentiment-by-category, and store-level performance.

Live Web Application: A Streamlit-based dashboard for real-time review sentiment testing and product recommendation browsing.

DevOps & Deployment: Containerizing the backend and frontend with Docker and automating tests and deployment through GitHub Actions CI/CD to cloud hosting.

5. Methodology

This project follows an end-to-end analytics engineering pipeline, from raw data sourcing to live business-facing insight.

5.1 Data Sourcing, Sampling & Warehouse

Stream each target category's raw review and metadata files directly from the Amazon Reviews 2023 (McAuley Lab) repository, without downloading the full multi-gigabyte source files.

Apply reservoir sampling to draw a uniformly random ~2–3 million review subset across the four categories, then retrieve only the matching product metadata.

Restructure the sampled data into 5 relational tables (reviews, review_text, products, stores, users) and load them into PostgreSQL via pgAdmin 4, enforcing primary/foreign keys and building star-schema analytical views.

5.2 Data Cleaning & Feature Engineering

Connect Python (SQLAlchemy) to PostgreSQL; handle nulls in price and main_category, and parse Unix timestamps into readable dates.

Vectorize review_text/review_title (for sentiment) and product_title/category/main_category (for recommendation) separately using TF-IDF with unigrams and bigrams.

5.3 Machine Learning Core

Model 1 (Sentiment Analysis): TF-IDF (1–2 gram) features from review text and title, trained with a linear Support Vector Machine (via SGDClassifier for scalability to millions of rows) to classify reviews as positive, negative, or neutral — using only text features to avoid leaking the numeric rating into the model.

Model 2 (Content-Based Recommendation): TF-IDF vectors built from product title, category, and main_category, with a Nearest-Neighbours (cosine similarity) index used to retrieve the top-N most similar products for any given item, avoiding the need to compute a full pairwise similarity matrix.

Persist trained models with Joblib and track experiments (accuracy, F1, precision/recall) with MLflow.

5.4 Analytics, Visualization & BI

Power BI: Connect directly to PostgreSQL and build a multi-page interactive report covering rating trends over time, sentiment distribution by category and store, and price-versus-rating relationships (in place of order-level GMV/AOV metrics, since the dataset contains review and listing data rather than transaction records).

Streamlit: Provide a user-facing live web dashboard where a manager can paste review text to test sentiment, or select a product to see its top recommended alternatives.

5.5 DevOps & Deployment

Package backend and frontend into Docker containers.

Automate tests with GitHub Actions CI/CD and deploy live to cloud hosting.

6. Primary Dataset

The project uses the Amazon Reviews 2023 dataset published by the McAuley Lab (UC San Diego), one of the largest publicly available e-commerce review corpora, spanning 33 product categories with hundreds of millions of reviews and tens of millions of products. Rather than using the dataset in full, a curated subset of approximately 2–3 million reviews was drawn from four categories — Cell_Phones_and_Accessories, Electronics, Video_Games, and Tools_and_Home_Improvement — using streaming and reservoir sampling, then restructured into five clean relational tables. 7. Conclusion

This project demonstrates an end-to-end, production-oriented integration of relational data engineering, natural language processing, and business intelligence into a single decision-support platform for e-commerce operations. The first major achievement is data engineering at scale: roughly 2–3 million reviews and their linked metadata were streamed and reservoir-sampled from a multi-hundred-million-row public corpus without ever downloading the source files in full, then normalized into five clean, foreign-key-linked relational tables inside PostgreSQL — a workflow that mirrors how real analytics teams curate manageable, high-quality subsets from massive raw data lakes.

The second achievement is a pair of complementary, purpose-fit machine learning models rather than one-size-fits-all algorithms. The sentiment classifier was deliberately built on TF-IDF text features alone — excluding the numeric rating — so that it genuinely learns language patterns instead of trivially echoing a label derived from that same rating. The recommendation engine was deliberately built as a content-based system rather than collaborative filtering, because exploratory analysis of the users table showed that the overwhelming majority of reviewers have only one or two recorded interactions; a similarity-based approach on product text sidesteps this sparsity and still produces meaningful “customers who liked this might also like” style suggestions without a cold-start penalty.

The third achievement is turning both models into something a non-technical stakeholder can actually use: a live Streamlit application lets a manager paste a review and instantly see its sentiment, or pick a product and see its nearest textual neighbours, while a Power BI layer aggregates the same warehouse into rating-trend and sentiment-by-category views for executive reporting. Finally, wrapping the whole pipeline in Docker containers with a GitHub Actions CI/CD workflow ensures the system is not a one-off notebook exercise but a reproducible, version-controlled, and cloud-deployable artifact — closing the loop from raw, noisy customer feedback to a clean warehouse, to trained models, to an interface a business user can act on.

7.1 Key Highlights (Core Deliverables at Completion)

Curated Relational Dataset: ~2–3 million Amazon Reviews 2023 records restructured into 5 clean, foreign-key-linked PostgreSQL tables, built via a reproducible streaming/reservoir-sampling pipeline.

Trained ML Models: Two production-ready .joblib models — a leakage-free Sentiment Classifier and a Content-Based Product Recommender — logged via MLflow.

Executive BI Dashboard (Power BI): A multi-page business intelligence report tracking rating trends, sentiment drivers, and store-level performance.

Live Web App (Streamlit): A deployed dashboard allowing anyone to test review sentiment and browse product recommendations in real time.

Dockerized Codebase & CI/CD Pipeline: A clean GitHub repository featuring automated tests, a reproducible Docker container, and an architectural README.

7.2 Limitations

Sparse User Histories: Most users have only 1–2 recorded reviews, which limits collaborative filtering and was the direct reason a content-based recommendation approach was chosen instead.

Rating-Derived Sentiment Label: The ground-truth sentiment label is itself derived from the star rating, so model evaluation must rely on held-out text-only performance rather than assuming independence from rating.

Cold-Start Products: Newly listed products with sparse or missing metadata (e.g., missing price/main_category) may receive lower-quality recommendations.

8. Future Scope

Hybrid Recommendation: Combine the content-based engine with collaborative filtering (e.g., ALS) for the subset of users who do have sufficient review history, blending both signals.

Graph-Based Recommendation: Explore Graph Neural Network models (e.g., LightGCN, NGCF via the RecBole library) to exploit the user–item interaction graph despite its sparsity.

Transformer-Based Sentiment: Fine-tune a lightweight transformer (e.g., DistilBERT) on a sampled subset to benchmark against the TF-IDF + SVM baseline.

Real-Time Ingestion: Introduce a streaming pipeline (e.g., Kafka) to replace batch loading with near real-time updates.

Category Expansion: Extend the sampling and modeling pipeline to additional Amazon Reviews 2023 categories beyond the initial four.

Transactional Data Integration: If order/transaction-level data becomes available, extend the BI layer to true GMV/AOV/RFM financial metrics.
